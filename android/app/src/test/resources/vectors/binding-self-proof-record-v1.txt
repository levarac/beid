# use the identical field semantics (cross-referenced against the iOS
# source above, not run), so this file is the "same result for same
# inputs" (criterion 3) anchor without needing an iOS Simulator run.

# fixtures in Barnard's own suite (different wallet addresses/keys) — they
# are NOT a single coherent wallet-binding ceremony, only two independently
# barnard-pinned field-mapping checks. Do not read
# binding_wallet_signature_hex as cryptographically valid for
# binding_device_signature_*; it is a placeholder input for the mapping
# check only (walletSignatureHex is stored verbatim, uninterpreted, by
# design — Android does not verify wallet signatures, spec-133's own
# Non-goal).
